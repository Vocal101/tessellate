How to play

Goal

Destroy every enemy structure. Mine Lumen with Motes, build production, and out-think the other lattice.

Controls

  • Left drag box-select · Shift add · Double-click all of a type
  • Right click move / attack / mine / help build / set rally
  • A + click attack-move · S stop
  • Ctrl+1-9 set group · 1-9 recall (twice to jump)
  • Q W E R T Y command card · X cancel last in queue
  • Arrows / screen edge / middle drag scroll · wheel zoom
  • Space jump to selection · . idle Mote · F10 menu

Units

Buildings: Core (Motes, drop-off, +10 supply) · Conduit (+8 supply) · Forge (Pike, Glint) · Foundry (Runner, Bastion) · Spire (Prism) · Sentinel (tower).
